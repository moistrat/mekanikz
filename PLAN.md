# Mekanikz — Plan

A sibling to Cirkitz for mechanical engineering: same stack, layout and theme (orange accent), with a full course, a hands-on sandbox, games and a quiz.

## Pages
1. **Learn** – 6 units, 23 lessons, 18 interactive figures, check questions, progress tracking.
2. **Sandbox** – truss builder with live force analysis and bridge challenges.
3. **Games** – balance, hang-the-sign, cannon, loop-the-loop, gear train, concept sprint, bridge builder.
4. **Quiz** – generated numeric problems by topic and level with worked solutions.

## Tech
Vite + React + TypeScript, plain CSS (tokens copied from Cirkitz, accent `#ff8a3d`), Vitest, static deploy to GitHub Pages.

## Done when
Course content tests, solver tests and 2,000+ generated quiz questions pass; production build is clean; every page was loaded and exercised in the browser.

## Ideas for later
Cirkitz-style first-visit tutorial, beam and pulley sandboxes, 3D views, deflection and shear diagrams in the truss sandbox, more thermo and fluids lessons, share links for trusses.
